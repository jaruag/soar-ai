About SOAR-AI

SOAR-AI ingests security findings from a scanner (Trivy), normalises them into a common, source-agnostic format, and an LLM classifies each one as critical, review or likely noise, with a reason and a suggested action.

The goal is the same as a SOAR (Security Orchestration, Automation and Response): take the manual, repetitive work of triaging security findings and automate it, so a team only spends time on what needs human judgement.

Built with Python, FastAPI, Trivy and Anthropic Claude. Working prototype.
